# Исправления багов и упрощение кода — 28 октября 2026

Исправлены замечания аудитов текущего кода. Изменения проверяются локально
на Windows и Linux с Rust 1.99.1; физический Restore/Revive и установка драйверов
на реальное устройство не выполнялись.

## Ошибки восстановления и загрузки

- Ошибки Win32 об отключении устройства распознаются вместе с ошибками nusb.
  Apple USB сохраняет исходную ошибку также при немедленном отказе отправки IN.
  Отмена запроса не приравнивается к физическому отключению.
- Манифесты, framed plist, ответы TSS, каталоги, authorization plist и plist bundles
  проверяются по глубине до построения дерева Value. Предел — 128 коллекций.
  Потоковый API существующей библиотеки plist используется с ограничением её
  minor-версии; отдельный XML/binary parser не добавлен.
- HTTP-чтение и запись имеют тайм-аут бездействия 120 секунд. Полная загрузка
  IPSW сохраняет неограниченную общую длительность. Тайм-аут ureq внутри
  io::Error распознаётся как причина для повтора загрузки.
- ZIP CRC файловых систем Restore/Recovery проверяется до отправки первого
  boot-компонента в Mac. Полное последовательное чтение stored image также
  проверяет CRC, в том числе после ASR validation seeks и возврата в начало.
  Подготовка больших образов требует дополнительного чтения файловых систем.
- Проверенный partial публикуется через существующий tempfile::persist_noclobber:
  в Windows используется перемещение без перезаписи, поддерживаемое exFAT.
  Коллизия с файлом назначения сохраняет чужой файл и partial для повтора.

## Журналы

Очередь диагностики имеет бюджет 16 MiB с учётом payload и накладных расходов
записей. При перегрузке DEBUG/TRACE отклоняются до копирования больших дампов;
число пропусков записывается отдельным WARN. INFO/WARN/ERROR передаются
синхронно, если очередь заполнена. Flush завершает запись принятых сообщений.
Эта политика ограничивает память и сохраняет важные сообщения, явно показывая
потерю подробной диагностики при перегрузке.

## Удалённая лишняя механика

- Локализация выбирает известный шаблон и затем вставляет явно переданные
  параметры. Перебор шаблонов по specificity, capture готовых строк,
  рекурсивный перевод значений и эвристический список имён данных удалены.
- Из языковых каталогов удалены форматы, относящиеся только к диагностике.
  Устаревшие ключи в сторонних переводах игнорируются; актуальные переводы,
  проверка placeholders, выбор языка и английский fallback сохраняются.
- UAC pipe передаёт только JSON-записи Record. Общий строковый протокол
  ZALIVKA_EVENT и его проверки Transfer/OperationWeights удалены; внутри
  процесса прогресс по-прежнему передаётся Rust-событиями.
- Логи GUI идут через Journal.pending. Обработка state events больше не
  возвращает лог-записи и не выполняет дублирующую синхронную запись.
- Заголовки файловых диалогов переводятся до запуска фоновой задачи.
  Остальные фоновые задачи не клонируют Localizer и не устанавливают его guard.
- Идентификатор сборки использует version, revision/dirty и время. Рекурсивный
  fingerprint исходников удалён; уникальные опубликованные EXE, SHA-256
  бинарника и metadata compiler/target/profile/features сохраняются.
- Удалён второй профилировщик ASR/FileData. Используются существующие счётчики
  Progress, время и скорость; mux сохраняет итоговые показатели USB и ожиданий.
- Атомарная запись языка и темы использует одну небольшую функцию. Убраны
  повтор абсолютного env lookup и повторная проверка готовности драйвера.
- Из отдельного сервисного cleanup.ps1 удалены ветви старой NCM-функции;
  широкая очистка Apple-пакетов и штатный drivers reset сохраняют свои разные
  назначения. Устаревшее описание NCM в документации пакета удалено.
- Каталог docs больше не исключён из Git; README и вывод plan ссылаются на
  доступные исходники документов проверки.

## Проверки

Итоговый прогон Rust 1.99.1: Windows — 475 тестов прошли, 8 ignored;
Linux — 439 тестов прошли, 6 ignored. На обеих платформах прошли
форматирование, Clippy всех targets/features с `-D warnings` и отдельный
`cargo check --no-default-features`. Parser Windows PowerShell подтвердил
синтаксис build.ps1 и cleanup.ps1. Локальные ссылки README/docs проверены.

Используются штатные команды:

```sh
cargo +1.99.1 fmt --all -- --check
cargo +1.99.1 clippy --locked --offline --all-targets --all-features -- -D warnings
cargo +1.99.1 test --locked --offline --all-features
```

Новые регрессии проверяют глубокие XML/binary plist, корректный код завершения
CLI на повреждённом манифесте, Win32 disconnect и сохранение причины отказа IN,
CRC stored OS после seek, зависшее HTTP body и классификацию тайм-аута,
публикацию partial и коллизию назначения, бюджет очереди и явное предупреждение
о пропусках, непрозрачность параметров перевода и совместимость старых каталогов.
Тесты GUI используют настоящий путь журнала и сохраняют проверки ошибок диска.
PowerShell-скрипты проверяются parser Windows PowerShell без выполнения очистки.

Ignored-тесты производительности, большой ZIP64 и реальный доступ к Apple
не запускались. Эти проверки не подтверждают физическое восстановление Mac.
