# Комплексный аудит — 26 октября 2026 года

Проверены CLI, GUI, загрузка и кэш прошивок, IPSW, IMG4, AEA, TSS, firmware
updaters, restore, ASR, FDR, mux, USB, USB-сеть, Windows-драйверы и скрипты.
Ниже — 50 исправленных замечаний: ошибки, несогласованности проверок и
обработки пограничных состояний. Это не список из 50 критических уязвимостей.

## Сопутствующая уборка

- `build.rs` отслеживает packed-refs, чтобы изменение упакованной Git reference
  участвовало в обновлении build identity.
- В catch блока `cleanup.ps1` ErrorAction задан явно: вывод ошибки больше не
  прерывает обработчик до предусмотренного `exit 1`.
- Локальные отчёты `scripts/runs` и резервный `.cache` исключены из Git.
- Добавлены отсутствовавшие README и `docs/validation.md`, на которые уже ссылались
  CLI и его машинный отчёт.

## Проверка и границы

Новые и расширенные тесты находятся рядом с соответствующими группами в
`tests/unit` и `tests/protocols`. Они покрывают restart loops, сохранение partial,
IPv6 SOCKS, правила TSS, замену манифеста, CPIO trailer, переподключение,
неподходящие USB endpoints, IP fragments, GUI bursts и состояние Progress.

Windows-код дополнительно проверяется компиляцией всех targets/features под
`x86_64-pc-windows-gnu`. PowerShell-скрипты проверяются штатным parser Windows
PowerShell 5.1. Физический USB, установка драйверов и аппаратное восстановление
в этом аудите не выполнялись; подробнее в [validation.md](validation.md).

Новые зависимости и архитектурные слои не добавлялись. Изменения используют
существующие проверки boot-компонентов, bounded reader, tempfile и общий код
подписи; перечитывание BuildManifest не является полной защитой от изменения
остальных байтов IPSW во время работы.
